# Next.js 16 + Installable PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade SPGPS to Next.js 16 and add an installable PWA with app-shell caching and a Thai offline page, without caching live GPS or API data.

**Architecture:** Bump Next to 16 (Turbopack default), keep auth edge protection, add `manifest.ts` + icons, serve a public `/offline` page, and register a Serwist service worker via `@serwist/turbopack` with a narrow CacheFirst policy for `/_next/static` only.

**Tech Stack:** Next.js 16, React 19, `@serwist/turbopack`, `serwist`, `esbuild`, existing SiriPro GPS UI tokens

## Global Constraints

- PWA scope: installable + app-shell cache + offline page only
- Do not enable `cacheComponents`
- Do not use Serwist `defaultCache`
- Never cache `/api/*`, auth, map tiles, or live location fetches
- Service worker registration: production only
- Icons derived from `android/play-store/icon-512.png`
- Manifest name: `SPGPS — SiriPro GPS`; short_name: `SPGPS`; lang: `th`; start_url: `/`; display: `standalone`
- Spec: `docs/superpowers/specs/2026-11-20-next16-pwa-design.md`

- [ ] **Step 3: Create Serwist route**

```ts
// src/app/serwist/[path]/route.ts
import { spawnSync } from "node:child_process";
import { createSerwistRoute } from "@serwist/turbopack";

const revision =
  spawnSync("git", ["rev-parse", "HEAD"], { encoding: "utf-8" }).stdout?.trim() ||
  crypto.randomUUID();

export const { dynamic, dynamicParams, revalidate, generateStaticParams, GET } =
  createSerwistRoute({
    additionalPrecacheEntries: [
      { url: "/offline", revision },
      { url: "/icons/icon-192.png", revision },
      { url: "/icons/icon-512.png", revision },
    ],
    swSrc: "src/app/sw.ts",
    useNativeEsbuild: true,
  });
```

- [ ] **Step 4: Create custom SW (no defaultCache)**

```ts
// src/app/sw.ts
/// <reference lib="esnext" />
/// <reference lib="webworker" />
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";
import { CacheFirst, NetworkOnly, Serwist } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

declare const self: ServiceWorkerGlobalScope;

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    {
      matcher: ({ url, sameOrigin }) =>
        sameOrigin && url.pathname.startsWith("/api/"),
      handler: new NetworkOnly(),
    },
    {
      matcher: ({ url, sameOrigin }) =>
        sameOrigin && url.pathname.startsWith("/_next/static/"),
      handler: new CacheFirst({
        cacheName: "spgps-static",
      }),
    },
  ],
  fallbacks: {
    entries: [
      {
        url: "/offline",
        matcher({ request }) {
          return request.destination === "document";
        },
      },
    ],
  },
});

serwist.addEventListeners();
```

- [ ] **Step 5: Register via SerwistProvider in production**
