# คู่มือผู้ใช้ SPGPS (Viewer) — Design

**Date:** 2026-11-20  
**Status:** Implemented  
**App:** SiriPro GPS

## Goal

สร้างคู่มือการใช้งานสำหรับผู้ใช้ทั่วไป (Viewer) บนเว็บเบราว์เซอร์ ภาษาไทยทั้งเล่ม พร้อมภาพหน้าจอจริง ส่งมอบเป็น HTML พิมพ์ได้ / Export PDF ได้ โดยไม่ฝังในแอป

## Decisions (from brainstorming)

| Topic | Choice |
|-------|--------|
| Audience | Viewer เท่านั้น |
| Channel | เว็บเบราว์เซอร์ |
| Language | ไทยทั้งเล่ม |
| Delivery | HTML พิมพ์ได้ → Save as PDF จากเบราว์เซอร์ |
| Approach | แนวทาง 1 — HTML + screenshots จริง |
| Not in scope | Admin, Sync/worker, Android app, ติดตั้งเซิร์ฟเวอร์ |

## Delivery layout

```
docs/user-guide/
  viewer.html              # เล่มคู่มือ (เปิดในเบราว์เซอร์ → พิมพ์/Save as PDF)
  README.md                # วิธีเปิดและ export PDF (สั้นๆ)
  images/
    01-login.png
    02-login-forgot-link.png
    03-sidebar-nav.png
    04-map-overview.png
    05-map-filters.png
    06-map-device-detail.png
    07-history-overview.png
    08-history-route.png
```

- `viewer.html` เป็น self-contained relative paths ไปยัง `images/`
- ไม่ต้องมี build step; เปิดไฟล์ตรงๆ หรือผ่าน static server ก็ได้
- CSS ในไฟล์เดียวกัน รองรับ `@media print` (A4, ตัดหน้าตามบท, ภาพไม่แตกขอบ)

## Screenshot capture

1. รันแอปในเครื่อง (หรือ URL ที่องค์กรใช้จริง) แล้วล็อกอินด้วยบัญชี **Viewer** (ไม่ใช่ Admin — เพื่อไม่ให้เมนูแอดมินปรากฏในภาพ)
2. ใช้เบราว์เซอร์เดสก์ท็อป ความกว้างประมาณ 1280–1440px
3. ถ่ายด้วย Playwright / browser tools — เก็บ PNG ลง `docs/user-guide/images/`
4. ถ้าข้อมูลจริงอ่อนไหว (ชื่อคน, พิกัดละเอียด): ใช้ environment ทดสอบ หรือเบลอเฉพาะที่จำเป็นโดยยังอ่าน UI ได้
5. ภาพต้องแสดง UI ปัจจุบันของ SiriPro GPS (ไม่ใช้ mock / ภาพเก่าจากสโตร์)

รายการภาพขั้นต่ำ: 8 ไฟล์ตามตาราง Delivery layout  
ถ้าจับภาพรวมได้ครบในน้อยกว่า 8 ไฟล์โดยไม่เสียความชัด อนุญาตรวมได้ แต่ทุกบท 2–5 ต้องมีภาพอย่างน้อยหนึ่งภาพ

## Writing style

- ภาษาไทย สั้น ชัด เป็นขั้นๆ (1, 2, 3…)
- อ้างปุ่ม/เมนูด้วยชื่อบนจอจริง และ **ตัวหนา**
- ไม่สอน Admin, ไม่ใส่ env / คำสั่ง terminal
- ไม่ใส่รหัสผ่านตัวอย่างของ production

## Print / PDF behavior

- หน้าปกสั้น: ชื่อ “คู่มือการใช้งาน SPGPS — สำหรับผู้ใช้ทั่วไป (Viewer)”
- แต่ละบทขึ้นหน้าใหม่เมื่อพิมพ์ (ถ้าได้โดยไม่เหลือหน้าว่างเกิน)
- ภาพมีคำบรรยายสั้นใต้ภาพ
- ผู้ใช้ export PDF: เปิด `viewer.html` → พิมพ์ → Save as PDF (ระบุใน README)

## Error handling & edge cases (ในเนื้อหาคู่มือ)

- อีเมลหรือรหัสผ่านไม่ถูกต้อง
- ลืมรหัสผ่าน → ใช้ลิงก์บนหน้า login
- Viewer เห็นเฉพาะกลุ่มที่ Admin มอบสิทธิ์
- ไม่มีอินเทอร์เน็ต → ใช้งานไม่ได้ (ระบบต้องการเครือข่าย)

## Out of scope

- หน้าเว็บ `/help` ในแอป
- คู่มือ Admin / Android
- แปลอังกฤษ
- Auto-generate PDF ใน CI
- วิดีโอสอนใช้งาน

## Success criteria

1. มี `docs/user-guide/viewer.html` เปิดแล้วอ่านครบ 6 บทได้โดยไม่พึ่งแอป
2. มีภาพจริงจากหน้าจอ Viewer อย่างน้อยตามบท 2–5
3. พิมพ์ / Save as PDF จากเบราว์เซอร์ได้โดยภาพและข้อความอ่านได้
4. ไม่มีเนื้อหาหรือภาพที่เผยเมนู/หน้าที่เป็น Admin-only เป็นหลัก
