# คู่มือผู้ใช้ SiriPro GPS (Viewer)

คู่มือภาษาไทยสำหรับผู้ใช้ทั่วไป บนเว็บเบราว์เซอร์ พร้อมภาพหน้าจอจริง

## เปิดอ่าน

เปิดไฟล์นี้ในเบราว์เซอร์:

```text
docs/user-guide/viewer.html
```

หรือดับเบิลคลิกจาก File Explorer

## บันทึกเป็น PDF

1. เปิด `viewer.html` ใน Chrome หรือ Edge  
2. กด **Ctrl+P** (Windows) หรือ **Cmd+P** (macOS)  
3. เลือกเครื่องพิมพ์ **Save as PDF** / **Microsoft Print to PDF**  
4. เปิด **Background graphics** ถ้ามีตัวเลือก (เพื่อให้หน้าปกและสีสถานะชัด)  
5. บันทึกไฟล์

## โครงสร้าง

| ไฟล์ | คำอธิบาย |
|------|----------|
| `viewer.html` | เล่มคู่มือ 6 บท |
| `images/*.png` | ภาพหน้าจอจริงจากบัญชี Viewer |

## หมายเหตุ

- คู่มือนี้ไม่รวมการใช้งานแอดมินหรือแอพ Android  
- ภาพอาจมีชื่ออุปกรณ์จากสภาพแวดล้อมที่ใช้ถ่าย — สำหรับแจกในองค์กรเท่านั้น
